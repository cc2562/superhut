## 微信小程序：退出登录清除课表与教务信息展示

- 需求：退出登录后课表页不显示缓存课表（显示登录按钮空态），"我的"页不显示教务账号。
- 关键坑：上一轮的会话自愈会让退出后的任何 authenticated 请求静默重建微信会话（服务端
  logout 只撤销单会话、教务绑定无损），把用户"自动登录回来"。解法：`recoverWechatSession(hadAccessToken)`
  仅在请求发出时本机有 accessToken 才回退 wechat/login；无 token 一律抛 AUTH_REQUIRED。
- 微信会话改为按需显式建立：`ensureWechatSession()`（登录页 submit 前调用）；bootstrap 不再
  自动建会话，无 token 直接 switchTab 课表页空态。logout 增加 `clearTimetable()`。
- profile/timetable onShow 增加 `!storage.accessToken()` 早退（显示未登录/空态，不发请求）。
- 新增 `toastRequestError(error, fallback)` 统一查询页 AUTH_REQUIRED 提示。
- CI 全绿：51 项测试（6 领域 + 18 客户端 + 27 服务端）。

## 微信小程序：学生评教功能（复刻 Flutter）

- 复刻 Flutter `lib/pages/Commentary/`，三页流程：批次→待评列表→答题；三种方式：手动/单课一键/一键评所有。
- 学校接口（基址 HUT_ACADEMIC_BASE_URL = https://jwxtsj.hut.edu.cn，POST + Token header）：
  - 批次 `/njwhd/student/studentEvaluate` → `data` 列表（字段 BATCHID/EVALUATIONBATCH/KCLBMC/XQMC/PJ01ID/PJ05ID）
  - 列表 `/njwhd/student/teachingEvaluation?pj01id&batchId&pj05id&issubmit=all` → `data` 列表（isSubmitCode '1'已评）
  - 题目 `/njwhd/student/evaluationIndex?...` → `data.targetData[]`，过滤 parentTargetId=='' 的项；选项 optionName/optionId/optionScoreValue
  - 提交 `/njwhd/student/saveEvaluate` → **JSON body**，target 数组元素是**小写 `{targetid, targetval}`**（targetid=题目id，targetval=选项id）
- 自动评教算法（buildAutoEvaluationTargets，service 层导出纯函数）：第 1 题选 score<4.75、其余选 score>=4.75；无符合时兜底取最低/最高分。
- real provider 的 `post()` 扩展支持 JSON body（原来只发 URL query）。
- **坑**：api-contract 的 main/exports 指向 dist/index.js，改了 src 的 schema 后必须 `pnpm --filter @superhut/api-contract build`，否则 server 测试 import 到旧 dist → 新 schema 是 undefined → 500。
- CI 全绿：61 项测试（6 领域 + 18 客户端 + 37 服务端，其中评教 10 项）。
