# 阶段 0：真实接入核验单

## 自动化验证基线

- [x] 开发版登录页可直接运行真实微信会话、错误密码隔离、教务绑定及全部查询验证，只显示数量和请求 ID。
- [x] `stage0:serve` 只在服务端进程中临时接收 AppSecret；学号和原始密码只从小程序登录页提交给本机 BFF。
- [x] `pnpm --filter @superhut/server stage0:verify` 仅从交互终端读取 AppSecret、学号和原始密码，不接受凭据命令行参数；转换规则自动复用 Flutter 实现。
- [x] 验证输出限制为稳定错误码、状态、requestId、耗时和记录数量，不输出上游正文。
- [x] 合成契约 Fixture 覆盖空数据、字段类型变化、缺失结构、HTML/非 JSON、Token 失效、429、5xx 和超时。
- [x] 使用受控账号从开发版小程序运行完整验证并保存不含个人数据的结果摘要。

## 技术尖峰

- [x] 受控测试账号可经 BFF 登录，错误密码返回稳定错误码。
- [x] `/njwhd/noticeTab` 可区分有效、过期和学校服务错误；学校特有的 HTTP 500 + `code=401` 只在 Token 请求中映射过期。
- [x] 验证教学周、单周普通课和实验课；当前学期为空，上一个常规学期成功转换出真实课程。
- [x] 验证学期、成绩、考试、教学楼和空教室接口；成绩和考试为真实空状态，教学楼和空教室为正常非空状态。
- [ ] 记录 Token 典型寿命、并发行为和限流表现。
- [x] 契约测试验证非 JSON、HTML 登录页、字段缺失、429、一般 5xx、学校 500/401 和超时。

## 数据安全

- [x] BFF 不记录上游 URL、请求正文或响应正文，客户端登录正文受日志脱敏规则保护。
- [x] 仓库、构建输入、异常摘要和 BFF 输出中搜索不到测试密码、转换中间值、微信 code 和两类 Token。
- [x] 未保存原始响应；视觉核验产生的临时截图已删除，仓库未发现完整学号或真实个人数据。
- [x] 本次未出现验证码、MFA 或明确禁止代理访问；停止条件仍保留。

## Go/No-Go

技术验证已通过：真实微信会话、受控教务登录、当前空课表、上学期真实课表转换、三项查询服务和稳定错误分类均成立，且安全扫描未发现敏感信息落盘。
